## 설명
```
일본어 단어장 앱은 많지만, 문법 표현을 카드로 외우는 앱은 드뭅니다.
JLPT 문법카드는 N5부터 N1까지 필수 문법 표현 580개를 단어 외우듯 카드로 익히는 앱입니다.

■ 급수별 문법 카드
· N5 135개 · N4 114개 · N3 72개 · N2 133개 · N1 126개
· 모든 카드에 뜻, 접속 방법, 후리가나가 달린 예문과 해석 수록
· 예문 속 문법 부분을 색으로 강조해 한눈에 확인

■ 모르는 문법만 집중 반복
· "알고 있음 / 모름"을 스와이프로 간단하게 체크
· 모름으로 표시한 문법은 다음 학습 때 새 문법과 섞여서 다시 등장
· 처음 보는 문법은 NEW, 본 적 있는 문법은 "3일 전", "모름 2회"처럼 표시
· 한 번에 학습할 카드 수와 복습 비율을 자유롭게 설정

■ 예문 음성 듣기
· 일본어 음성으로 예문을 들으며 발음과 함께 익히기
· 카드 넘길 때 자동 재생, 읽기 속도 조절

■ 평생 이용권
· 무료로 1사이클 체험 후, 한 번 결제로 모든 기능을 평생 무제한 이용
· 구독이 아닌 1회 결제, 자동 갱신 없음

JLPT 시험 준비, 일본어 문법 복습, 독학하는 분들께 추천합니다.
```
