# App Store Connect 입력 전체 가이드

위에서부터 순서대로 하면 된다. `[필수]`가 없는 항목은 비워 둬도 심사에 문제없다.

---

## 0. 계정 (한 번만)
**App Store Connect 홈 → 비즈니스**
- [필수] **유료 앱(Paid Apps) 계약** → 동의
- [필수] **은행 계좌**: 본인 명의 국내 계좌, 은행 SWIFT 코드, 예금주 영문명(개발자 계정 이름과 동일)
- [필수] **세금 양식**: 미국 W-8BEN (개인) → 국적 대한민국, 한·미 조세조약 적용
- 계약 상태가 **활성(Active)** 이 되어야 앱 내 구입을 제출할 수 있다 (며칠 걸릴 수 있음)

## 7. 빌드 업로드 (Mac)
```bash
cd jlpt-grammar-cards && git pull
cd ios && xcodegen generate && open GrammarCards.xcodeproj
```
1. Signing & Capabilities → Team 선택, Automatically manage signing 체크
2. 상단 기기 → **Any iOS Device (arm64)**
3. Product → **Archive**
4. Organizer → **Distribute App** → App Store Connect → Upload → 기본값으로 Next
5. 10~30분 후 App Store Connect → **TestFlight** 에 빌드 표시
- 다시 올릴 때는 ios/project.yml 의 `CURRENT_PROJECT_VERSION` 을 1 올리고 `xcodegen generate`

## 8. TestFlight (실기기 확인, 선택이지만 강력 추천)
1. TestFlight → 내부 테스트 → ＋ 그룹 만들기 → 본인 Apple ID 추가
2. 빌드를 그룹에 추가
3. 아이폰에 **TestFlight** 앱 설치 → 초대 수락 → 설치
4. 확인할 것: 카드 넘기기, 소리, 무료 1사이클 → 결제 화면, 결제(샌드박스라 실제 결제 안 됨), 구매 복원

## 9. 제출
- 버전 페이지 오른쪽 위 **심사에 추가 → 심사에 제출**
- 빠진 항목은 빨간 글씨로 표시됨
- 심사 보통 1~3일. 거절되면 해결 센터에 사유가 오고, 수정 후 다시 제출
